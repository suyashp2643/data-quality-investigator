## Revision: implemented, live outcome pending

Protocol v2 explicitly states that tool definitions are not observations. The controller requires
all four fault checks before accepting a final diagnosis. Premature final answers get corrective
feedback; they consume the existing six-call budget. Budget exhaustion produces an incomplete
attempt rather than a healthy verdict. All tools remain read-only and allowlisted. The final
fault set is still generated by the model and scored with the unchanged scoring function.
The rules and single-shot baseline prompts and behavior are unchanged.

This is a controller and prompt change, not a demonstrated performance improvement. The guard
requires four checks and therefore constrains autonomy; it does not make the model more accurate
than the rules. Synthetic public cases do not establish production or real-world generalization.
